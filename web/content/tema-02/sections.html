Del Hub a memoria

La primera carga descarga archivos; después la caché puede reutilizarlos.

  1. IdentificadorElige una versión del Hub.
  2. ArchivosDescarga configuración y pesos.
  3. MemoriaCarga el modelo en CPU o GPU.

Una API, muchas arquitecturas

from_pretrained carga los archivos que describe el identificador.

from transformers import AutoImageProcessor, AutoModelForImageClassification

model_id = "google/vit-base-patch16-224"
processor = AutoImageProcessor.from_pretrained(model_id)
model = AutoModelForImageClassification.from_pretrained(model_id)

El notebook utiliza este patrón. El modelo, sus requisitos de memoria y las etiquetas dependen del identificador elegido.

Una prueba rápida

Un pipeline prepara la entrada y devuelve una salida con el formato de la tarea.

from transformers import pipeline

classifier = pipeline("image-classification",
                      model="google/vit-base-patch16-224")
result = classifier("imagen.jpg")
